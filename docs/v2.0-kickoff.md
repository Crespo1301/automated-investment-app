**Prepared 2026-06-02 EOD.** v1 is closed (`v1.1.0`); version is now
`2.0.0-dev`. This is the concrete, ordered plan so the v2.0 build starts
without re-deciding anything. Decisions already locked (see
[`v2.0-operating-model.md`](./v2.0-operating-model.md)):

  transparency/glass, no glow.** Solid fills, hairline borders, flat
  dense panels, Segoe-style type. Must read as a full version jump.
- **Autopilot:** full rewrite authority, safety gates preserved.
