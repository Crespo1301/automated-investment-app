## The operating model (this is the default now)

Two tiers, by design:

| Tier | Who | Cadence | Cost | Responsibility |
|---|---|---|---|---|
| **Strategy** | **Claude (Opus 4.x), supervised chat** | **~15 min** | tokens/wake | Research, founded entries, exit judgment, overriding the engine when it has an edge, risk posture |
| **Reflex** | **Deterministic autopilot** (`app.worker --autopilot-loop`) | **30 s** | **$0 / 0 tokens** | Stops, spread guards, dup-suppression, fallback fills when Claude is absent |

**Why this split:** the 30 s loop is pure math — zero LLM cost — so it is
already the cheapest possible fast tier; there is no value in putting a
cheaper model on it. Intelligence belongs on the slow loop, where
synthesis (research, catalysts, concentration, regime) actually pays off.
This was validated live on 2026-06-02: green on a red tape with every
guardrail intact.

**Operating rules:**
- The autopilot stays **armed** as the always-on secondary. Do **not**
  disable it to "take over" — disabling kills the loop process and
  re-enabling does not restart it. Override by placing founded trades on
  top of a running engine.
- Claude is the **primary decision-maker** for entries and exits when
  present; the engine is the fallback "when Claude is unable to."
- Always verify `last_heartbeat_at` freshness, not just `enabled: true`.
- Per-`/loop` wake token cost grows over long sessions; for durable
  cadence prefer a `/schedule` cloud cron over an open session loop.

## v2.0 program — workstreams

### 1. Design revamp — "Microsoft-enterprise" (DECIDED)
Kill the "AI look." Target: a slick, solid, professional console that
reads as a **full version jump**, not a reskin.
- **Palette:** neutral grays (surface `#F3F3F3`) with a **finance-green
  accent (`#107C10`)**. Semantic red/green for loss/gain.
- **Hard rules:** **no gradients, no transparency/acrylic/glass, no
  glow/blur**. Solid fills, hairline borders, defined panels, system-like
  density and typography (Segoe-style). Flat, calm, dense, trustworthy.
- **Goal:** immediately obviously different from v1.0.
- Preserve all safety copy: confirmations, kill-switch, PDT guard,
  spread guards, deterministic explanations.

### 2. Autopilot / autotrader audit + rewrite (DECIDED: full rewrite authority)
Full authority to refactor and recreate the trading engine, **preserving
the deterministic safety gates**. Seeded by the v1 retrospective:
- **Fix exits.** v1 autopilot enters but does not exit cleanly (manual
  exits dominated). First-class exit lanes mirroring entry lanes.
- **Validate lane edge** on v1's ~132 real fills before re-implementing
  all five lanes; cut lanes without demonstrated edge.
- **Drop the redundant daily-trade cap** (PDT + BP guards already bound).
- **Idempotent client_order_ids** keyed on `(date, lane, symbol, intent)`
  (done in v1 pre-release; keep).
- **JSONL audit store → SQLite** (queryable, rotatable).
- **Single-process orchestrator with file lock**; no parallel runners.
- **Backtest harness** using the 132 v1 fills as ground truth.
- Everything in service of the prime directive: **grow portfolio value
  as much as possible** within the risk gates.
